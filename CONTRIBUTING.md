# Contributing

Contributions should preserve the project’s synthetic-data and evaluation-only boundary.

1. Create a focused branch.
2. Do not add real names, contact details, addresses, identity documents, bank information, client agreements, negotiation material, secrets or unverified business claims.
3. Keep new records visibly marked `DEMO` or `synthetic`.
4. Preserve separation of duties and customer record isolation.
5. Run lint, type checking, tests, the production build, dependency audit and secret scan.
6. Explain affected portals and include safe test evidence in the pull request.

By submitting a contribution, you confirm you have the right to provide it. Acceptance does not change the copyright and evaluation notice or grant an open-source licence.
