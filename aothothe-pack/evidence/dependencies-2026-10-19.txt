Residual scope assessment:
- @cloudflare/vite-plugin, Wrangler and Miniflare provide build/deploy/local-emulator tooling. Their dependency trees include vulnerable Sharp 0.34.5, Undici and ws copies.
- Vite findings concern development-server Windows path handling and editor integration. The local preview binds 127.0.0.1; the published artifact is a built Worker rather than a Vite development server.
- ESLint/Next lint plugin, fast-glob, micromatch, braces and brace-expansion handle lint/build file patterns. Babel and Browserslist handle source transformations and browser targets.
- Drizzle Kit and its esbuild-kit/esbuild chain handle schema generation. js-yaml appears under the ESLint configuration loader. fflate is required by @shuding/opentype.js through Satori in the framework dependency tree; its classification must not be simplified to lint-only tooling.
- Vinext remains listed through its CommonJS/dynamic-import/glob build plugin chain; the framework itself also supplies deployed runtime code. Its devDependency placement alone cannot prove the deployed runtime unaffected.
- Every residual node listed above has lockfile dev=true. That describes installation classification, not a proof of runtime safety. The 0-production/24-full split must be retained in release notes.
- No critical-severity findings were reported by either fresh audit. This is a point-in-time npm audit, not a complete security assessment.
