# Responsible disclosure

Do not include credentials, personal information, client documents, bank data, private URLs or exploit details in a public issue.

For a suspected vulnerability, contact Aothothe Technologies through its verified private business channel and include only the minimum information needed to reproduce the issue. If no verified private channel is available, open a minimal GitHub issue asking maintainers for a secure reporting route without disclosing the vulnerability.

## Supported release

Security review is focused on the latest `v1.0.0-demo` evidence release. This is not production software and must not process real data.

## Scope boundaries

- Safe synthetic workflow testing is in scope.
- Social engineering, denial of service, real-person data entry, credential testing and attacks on hosting or third-party services are out of scope.
- No bounty or compensation is promised.
