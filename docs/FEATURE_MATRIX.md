# Detailed feature coverage

The interface navigation exposes all required major portals. Coverage is verified by automated workflow-contract tests and responsive browser tests.

| Control family | Evidence surface |
| --- | --- |
| Unique customer references | Mobile enquiry success and service inbox |
| Quote turnaround | Service-management SLA metrics and queue |
| Stock accuracy | Inventory count and reconciliation screens |
| Signed cash closes | Seller submission and supervisor-only close action |
| Bank exception assignment | Finance reconciliation and audit table |
| Obligation ownership/evidence | Contracts/tasks register |
| Training and pass target | Worker target panel and management dashboard |
| Release approval | System administration release/health state and CI |
| Customer isolation | Customer role screen and RBAC matrix |
| Four-eyes content | Content review/publish control and versions |
| Safe destructive actions | Disabled restore/deletion controls and session reset |

Quantitative values are proposed operating targets or synthetic observations, never historical Fatima results.
